# Date & Time Utility Application

A simple Python GUI application built using **wxPython** that provides useful date-related utilities such as finding the day of the week, calculating age, and counting the number of days until a specified date.

## Features

* 📅 **Date Validation**

  * Validates dates in DD-MM-YYYY format.
  * Handles leap years correctly.
  * Checks whether the entered day, month, and year are valid.

* 🗓️ **Day of the Week**

  * Determines the day of the week for a given date.
  * Example: 04-10-2026 → Sunday

* 🎂 **Age Calculator**

  * Calculates a person's current age based on their date of birth.

* ⏳ **Countdown**

  * Calculates the number of days remaining until a future date.
  * Displays a message if the entered date has already passed.

## Technologies Used

* **Python**
* **wxPython**
* **datetime module**

## How to Run

### 1. Install Python

Make sure Python is installed on your system.

### 2. Install wxPython

Open the terminal or command prompt and run:

```bash
pip install wxPython
```

### 3. Run the Application

Navigate to the project folder and run:

```bash
python miniproject.py
```

## Date Format

Enter dates using:

```text
DD-MM-YYYY
```

Example:

```text
04-10-2026
```
